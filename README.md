Ping-Pong game. It is super cool Ping-Pong game. You can Ping and you can Pong. Or you can Ping-Pong

For this program you must have installed:

1. Visual Studio code
2. In VS code download extension "Python"

And for playing You need to:

1. click "Ping-Pong.py"
2. click "Download raw file"
3. Open file with VS code
4. click "play" (it looks like green triangle)
